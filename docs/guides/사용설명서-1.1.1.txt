1. 시작과 데이터

간단하게 쓰려면 FK_YT-1.1.1-portable.zip을 권장합니다. 쓰기 가능한 새 폴더에 전부 풀고 FK_YT 폴더의 FK_YT.exe를 실행하세요. 포터블 데이터는 앱 옆 data 폴더에 저장됩니다.

FK_YT-1.1.1-Setup-x64.exe는 관리자 권한으로 시스템에 설치합니다. 기본 위치는 64비트 Program Files이며, 설치 화면은 영어입니다. 설치를 마친 뒤 시작 메뉴의 FK_YT (System)을 실행하세요. 앱 자체는 일반 사용자 권한으로 실행하고, 데이터는 각 Windows 사용자의 %LOCALAPPDATA%\FK_YT\data에 저장합니다.

두 방식은 같은 앱 DLL·기능·번들 도구를 사용합니다. 설치형 마커 FK_YT.install-mode를 임의로 옮기거나 지우지 마세요. runtime, worker, DLL과 법적 고지도 함께 보존하세요.

설치형 제거는 프로그램·공용 바로가기·등록 정보를 대상으로 하며 모든 사용자의 설정·로그인·기록·이어보기·다운로드를 보존합니다. 데이터 삭제 선택란은 없습니다. 직접 추가·수정하거나 잠긴 프로그램 파일은 남을 수 있습니다. 포터블은 앱을 닫고 폴더를 지우면 되지만, data를 함께 지우면 앱 데이터도 삭제됩니다.

앱을 업데이트하거나 데이터를 옮기기 전에는 종료하고 원본을 보관하세요. 포터블 ZIP은 새 빈 폴더에 풉니다. 설치형으로 자동 이전하지 않으며, 수동 복사할 때도 같은 Windows 사용자의 빈 데이터 폴더를 사용하세요. SQLite DB를 합치거나 사용 중인 데이터 폴더를 덮어쓰지 마세요.

2. 시청 기록: 전송 전 직접 선택

설정의 ‘YouTube 계정에 시청 기록 전송’은 기본으로 꺼져 있습니다. 새 선택 버전이 없는 이전 설정은 과거의 켜짐 값이 기본값이었을 수 있어 이번에 한 번 전송을 끄며, 이전 설정 안내를 표시합니다. 원하면 직접 켜 주세요. 이후 저장한 명시적 선택은 앱 재시작과 계정 변경 후에도 유지합니다. 시크릿은 저장한 선택을 바꾸지 않고 전송을 차단합니다.

전송을 꺼도 일반 모드의 로컬 시청 기록과 정확한 이어보기 위치는 유지합니다. 전송을 켜는 것만으로 예전 로컬 기록을 보내지는 않습니다. 켠 뒤 실제로 재생한 시간이 30초에 도달하거나, 30초보다 짧은 영상의 80%를 시청하면 새 전송 기록을 만듭니다. 일시정지·버퍼링·탐색·재생 위치 건너뛰기는 시청 시간으로 세지 않습니다. YouTube에서는 보낸 영상이 모두 시청한 것으로 표시될 수 있으며, 정확한 이어보기는 앱에 별도로 저장합니다.

승인된 기록은 계정·채널별 SQLite 대기열에 저장한 뒤 오래된 순서로 하나씩 전송을 시도합니다. 정상 재시작 후에는 전송 설정이 켜져 있고 연결된 계정·채널이 확인되면 한 번도 시도하지 않은 ‘대기’ 기록을 자동으로 계속 전송합니다. 전송 중 중단한 기록은 ‘결과 미확인’으로 보존하고 자동 재전송하지 않습니다. 실패한 기록도 보존하며 자동 재시도하지 않습니다. ‘전송됨’은 요청 응답을 확인했다는 뜻이며 YouTube 계정 기록의 실제 반영은 별도로 확인하세요.

전송 끄기·계정 전환이나 재연결·채널 전환·시크릿 진입은 아직 시도하지 않은 기록을 보류합니다. 다시 켜기·시크릿 종료·재시작만으로 보류를 풀지 않습니다. 설정에서 대기·보류·결과 미확인·실패 개수를 볼 수 있습니다. 선택한 계정·채널과 보류 이유를 확인하고, 안내가 있으면 채널 목록을 갱신한 뒤 ‘보류 기록 전송 재개’를 누르세요. 현재 계정·채널의 한 번도 시도하지 않은 보류 기록만 재개하며 실패·결과 미확인 기록은 다시 보내지 않습니다. ‘대기 상태 새로고침’은 저장소와 상태를 다시 확인하며 보류 해제나 계정 확인을 대신하지 않습니다.

세션·봇 확인·요청 제한 오류는 추가 전송을 보류합니다. 결과가 모호한 응답도 두 번 연속이면 나머지를 보류합니다. 그 외 한 번의 실패 뒤에는 다른 대기 기록을 계속 시도할 수 있습니다. 문제를 확인한 뒤 직접 재개하세요. 저장소 읽기·쓰기에 실패하면 전송을 멈추므로 저장소를 확인하고 대기 상태를 새로고침하세요. 백업은 앱을 닫고 DB와 설정을 함께 보존하며, 강제 재시도를 위해 대기열을 직접 수정하지 마세요. 시크릿에서는 대기열 조회·전송과 로컬 기록·이어보기 저장을 하지 않습니다. 비공식 계정 연동에는 서비스 정책 및 계정 접근 제한 위험이 있습니다.

3. 화면과 일반 재생

영화관 모드에서 댓글·추천 영역을 열어둘 수 있습니다. 댓글은 버튼을 눌러야 불러옵니다. 일반·영화관 창의 하단 조작부는 접고 다시 펼칠 수 있으며, 선택은 현재 앱 실행 동안 유지됩니다. 전체화면·팝아웃은 기존 자동 숨김을 사용합니다.

일반 영상에서 직접 0초로 이동한 뒤 확인된 0초는 이어보기 위치로 저장할 수 있습니다. 처음 로딩하며 자동 관측된 0초만으로 기존 이어보기를 지우지는 않습니다. 시크릿과 라이브에는 일반 영상 이어보기 저장을 적용하지 않습니다.

Shorts는 광고로 명시된 제공 카드만 거릅니다. 일반 영상이나 제작자의 유료 프로모션 표시까지 없애는 기능은 아니며, 모든 실제 광고 형태를 검증하지 않았습니다.

4. 라이브와 LIVE

탐색은 mpv가 확인한 로컬 캐시 구간만 사용하며, 중간에 없는 구간이 있을 수 있습니다. LIVE는 방송 현재 지점을 다시 열고 의도한 일시정지를 유지합니다. 시청 전에 받은 적 없는 구간이나 서버 DVR 전 구간을 가져오지는 못합니다.

확인된 라이브는 demuxer별 후방 RAM 캐시 예산 6 GiB를 사용합니다. 미리 6 GiB를 할당하는 것이 아니며 앱 전체 RAM 상한도 아닙니다. 전방 예산은 32 MiB로 유지하고 디스크 캐시는 사용하지 않습니다. 모든 과거 구간이나 일정한 되감기 시간을 보장하지 않습니다.

늦게 라이브로 판별되고 다음 영상 준비를 이미 시도했다면 원래 버퍼 예산이 유지될 수 있습니다. LIVE로 다시 열면 라이브 예산을 적용합니다. 일반 영상은 기존 32 MiB 전방·8 MiB 후방 예산을 사용합니다.

연결 끊김에는 방송 상태와 오류를 확인한 뒤 2·5·10초 간격으로 최대 세 번 재연결할 수 있습니다. 인증·접근·요청 제한 오류는 재시도하지 않습니다. 수동 일시정지·정지·영상/계정 변경·시크릿 전환은 복구를 취소합니다. 방송 종료를 확인해야 다음 영상으로 자동 이동합니다.

게스트·기본 로그인 슬롯 외 계정은 검증 가능한 단일 오디오·비디오 결합 HTTPS HLS가 필요합니다. 지원하지 않는 경우 다른 계정으로 바꾸지 않고 오류를 표시합니다. 라이브 채팅·예약 방송 대기·녹화는 포함하지 않습니다.

5. 실험적 도구 업데이트

설정의 yt-dlp·Deno 확인·다운로드·롤백·번들 복원은 수동 실험 기능입니다. 자동 온라인 확인이나 자동 설치는 없습니다. yt-dlp EXE·Python 패키지·EJS를 함께 준비하며 다음 앱 시작에 적용합니다. 현재 실행은 기존 도구를 계속 사용합니다. Python·mpv·FFmpeg는 이 기능으로 업데이트하지 않습니다.

재생이 잘 되면 번들 도구 유지를 권장합니다. 오프라인 검사를 통과해도 새 버전이 재생·목록·댓글·자막을 깨뜨릴 수 있습니다. 공식 HTTPS에서 YouTube 쿠키 없이 다운로드하며, 해시는 독립적인 게시자 서명을 대신하지 않습니다.

도구는 포터블 data\tools 또는 설치형 %LOCALAPPDATA%\FK_YT\data\tools에 저장합니다. 원본과 완료한 과거 버전은 보존하며 자동 정리·전체 용량 상한은 없습니다. 확인된 손상 후보는 현재 앱 실행 동안 롤백에서 제외되며, 재시작 후 선택 가능해져도 적용 전 재검증합니다. 일시적 접근 오류나 취소를 모두 손상으로 취급하지는 않습니다.

다운로드한 도구를 재배포하려면 해당 버전의 고지·대응 소스를 별도로 검토해야 합니다. 원래 릴리스의 소스 ZIP은 원래 번들 버전만 설명합니다.

6. 검증 범위와 개인정보

시청 기록 구현은 앞서 격리된 오프라인 검사에서 C# 핵심 50개 그룹·UI 17개 그룹과 Python 262개 검사를 통과했습니다. 기존 도구 업데이트 검사는 249개 assertion을 기록했고 native mpv 캐시 검사는 로컬 미디어를 사용했습니다. 서로 다른 검사 범위이므로 하나의 합계가 아닙니다. 일반 1.1.1 앱은 고정 SDK·캐시로 오프라인 publish했으며 컴파일러 경고가 없었습니다. 1.1.1의 새 수동 설치·제거나 실제 YouTube·계정 기록 전송 검증은 주장하지 않습니다. 제작자의 2026-10-17 Windows 10/11 설치·설치 후 실행과 재생·설치기 업데이트·제거 확인은 1.1에 해당합니다. 새 장시간·라이브 재생, 캐시 전체 채움, 공식 실험적 도구 활성화, 설치 시간과 세부 UAC·권한 검증은 이번 오프라인 검사의 범위 밖입니다.

시크릿은 IP를 숨기지 않으며 직접 다운로드한 파일을 삭제하지 않습니다. Firefox 전용 YouTube 프로필을 권장합니다. 쿠키·인증 토큰·data 폴더·개인백업은 제보에 첨부하지 마세요. 외부 구성 요소는 각 프로젝트의 라이선스를 따르며 원래 고지와 소스 안내를 보존합니다.

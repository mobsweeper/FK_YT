1. 起動とデータの保管

ポータブル版: FK_YT-1.1.2-portable.zip 全体を書き込み可能な新しいフォルダーに展開し、FK_YT/FK_YT.exe を実行してください。データはアプリの隣の data/ に保存します。インストール版: FK_YT-1.1.2-Setup-x64.exe を管理者権限で実行して英語の Setup 案内に従い、Setup を閉じてからスタートメニューの FK_YT (System) を開いてください。データは各 Windows ユーザーの %LOCALAPPDATA%\FK_YT\data に保存します。runtime、worker、DLL、法的通知とインストールモードのマーカーを一緒に保持してください。ファイルの公開状況と最終チェックサムは https://github.com/mobsweeper/FK_YT/releases/tag/v1.1.2 で確認してください。

バックアップや移動の前にアプリを終了してください。元の DB と設定を一緒に保管し、同じ Windows ユーザーで空の保存先にだけコピーしてください。SQLite DB の結合や使用中のフォルダーへの上書きは避けてください。data/ を削除すると、そのポータブル版のアプリデータも失われます。

2. オーディオモードのチェックボックス

通常の動画を音声で聴くには、サイドバーの「オーディオモード」を選択します。次の動画、または再生画面を離れて開き直したときに適用し、現在の再生はすぐには切り替わりません。ライブは引き続き映像と音声を再生します。

抽出器が利用可能なオリジナル音声を language_preference=10 と示す場合、アプリはオリジナルの音声専用ストリームを優先し、適切な専用ストリームがなければオリジナルの映像・音声結合ストリームのうち利用可能な最低解像度を選びます。オリジナルの結合ストリームは、吹き替えの音声専用ストリームや、より低解像度の吹き替え結合ストリームより優先します。オリジナルの表示がない応答では言語を推測せず、音声専用、最低解像度の結合ストリームの順という従来の互換選択を維持します。すべての吹き替えトラックを必ず遮断する保証はありません。

結合ストリームの代替再生では映像トラックを無効にして音声を再生しますが、映像データもダウンロードするため、音声データだけの通信や一定の通信量削減は保証しません。選択したアカウントは切り替えません。音声再生中は画質・字幕の操作を利用できません。

3. ライブの開始区間、LIVE と再接続

ライブの開始区間は、アプリが管理する native yt-dlp のフラグメント処理とパイプで、YouTube がまだ提供する範囲から開きます。期限切れの DVR 区間の復元や、元の最初の瞬間からの再生は保証しません。開始区間を開けない場合は LIVE で現在地点を開いてください。LIVE は意図した一時停止を維持します。巻き戻しは確認済みのローカルバッファ範囲だけを使用し、欠落区間がある場合があります。

ライブの後方圧縮パケットキャッシュの予算は 6 GiB で、データの到着に応じて増えます。事前確保量、RSS 上限、アプリ全体の RAM 上限、一定の巻き戻し時間ではありません。前方の予算は 32 MiB です。mpv のディスクキャッシュは無効ですが、一時的なフラグメント処理用の保存領域は別です。明示的なダウンロードはディスクに残ります。

放送状態とエラーを確認し、2・5・10 秒の間隔で累計最大 3 回まで自動再接続できます。上限後の最終状態確認は 4 回目の自動読み込みを開始しません。認証・アクセス・リクエスト制限のエラーでは復旧を停止します。手動の一時停止・停止、動画やアカウントの変更、シークレットの切り替えは復旧を取り消します。放送終了を確認してから次の動画を自動再生します。上限後に手動で試すには LIVE を使ってください。ライブチャット、予約配信の待機、録画は含みません。

4. 履歴、プライバシーとツール

YouTube 履歴の送信は初期設定でオフです。必要なら設定の「YouTube アカウントに再生履歴を送信」を自分でオンにしてください。ローカル履歴・再開位置は別で、オンにするだけで以前の履歴は送りません。保留中の記録はアカウント・チャンネルと理由を確認し、保留記録の送信再開操作で解除します。失敗・結果未確認の記録は自動再送しません。送信への応答確認と YouTube 履歴への反映確認は別です。

シークレットは保存した選択を変えず、送信とローカル履歴・再開位置の保存を停止します。IP を隠したり、明示的なダウンロードを削除したりはしません。Cookie、認証トークン、data/、個人バックアップを不具合報告に添付しないでください。

手動の実験的な yt-dlp・Deno 更新は次回起動時に適用します。Python・mpv・FFmpeg は更新しません。完成した旧版は自動整理や合計容量制限なしで保持します。取得した新版を再配布するには、その版の通知と対応ソースが必要です。

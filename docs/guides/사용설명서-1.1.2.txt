FK_YT 1.1.2 사용설명서
2026-10-19 갱신

1. 시작과 데이터 보존

포터블: FK_YT-1.1.2-portable.zip 전체를 쓰기 가능한 새 폴더에 풀고 FK_YT/FK_YT.exe를 실행하세요. 포터블 데이터는 앱 옆 data/에 저장합니다. 설치형: FK_YT-1.1.2-Setup-x64.exe를 관리자 권한으로 실행하고 영어 설치 안내를 따른 뒤, 설치기를 닫고 시작 메뉴의 FK_YT (System)을 여세요. 설치형 데이터는 각 Windows 사용자의 %LOCALAPPDATA%\FK_YT\data에 저장합니다. runtime, worker, DLL, 법적 고지와 설치 모드 표시 파일을 함께 보존하세요. 파일 접근 가능 여부와 최종 체크섬은 https://github.com/mobsweeper/FK_YT/releases/tag/v1.1.2 에서 확인하세요.

백업하거나 데이터를 옮기기 전에는 앱을 종료하세요. 원본 DB와 설정을 함께 보관하고 같은 Windows 사용자의 빈 대상 폴더에만 복사하세요. SQLite DB를 합치거나 사용 중인 폴더를 덮어쓰지 마세요. data/를 삭제하면 해당 포터블의 앱 데이터도 삭제됩니다.

2. 오디오 모드 체크박스

일반 영상을 소리로 들으려면 사이드바의 ‘오디오 모드’를 선택하세요. 다음 영상 또는 재생 화면을 나갔다 다시 열 때 적용되며, 현재 재생이 즉시 전환되지는 않습니다. 라이브는 계속 영상과 음성을 함께 재생합니다.

추출기가 사용 가능한 원본 트랙을 language_preference=10으로 표시하면 원본 전용 음원을 우선하고, 적합한 원본 전용 음원이 없으면 원본 영상·음성 결합 스트림 중 사용 가능한 가장 낮은 해상도를 선택합니다. 더빙 전용 음원이나 더 낮은 해상도의 더빙 결합 스트림보다 원본 결합 스트림을 우선합니다. 원본 표시가 없는 응답에서는 언어를 추측하지 않고 전용 음원, 최저 해상도 결합 스트림 순서의 기존 호환 선택을 유지합니다. 모든 더빙 트랙을 무조건 차단한다고 보장하지 않습니다.

결합 스트림 대체 재생은 영상 트랙을 끄고 소리만 재생하지만 영상 데이터도 다운로드하므로 오디오 데이터만 수신하거나 일정한 통신량 절감을 보장하지 않습니다. 선택한 계정은 바꾸지 않습니다. 오디오 재생 중에는 화질·자막 조작을 사용할 수 없습니다.

3. 라이브 시작 구간, LIVE와 재연결

라이브 시작 구간 재생은 앱이 관리하는 native yt-dlp 조각 처리와 파이프를 사용해 YouTube가 아직 제공하는 시작 구간을 엽니다. 만료된 DVR 조각을 복구하거나 원래 첫 순간부터 재생한다고 보장하지 않습니다. 시작 구간을 열 수 없으면 LIVE로 현재 지점을 여세요. LIVE는 의도한 일시정지를 유지합니다. 되감기는 확인된 로컬 버퍼 범위만 사용하며 중간에 없는 구간이 있을 수 있습니다.

라이브 후방 압축 패킷 캐시 예산은 6 GiB이며 데이터가 도착하면서 늘어납니다. 미리 할당하는 용량, RSS 상한, 앱 전체 RAM 상한 또는 일정한 되감기 시간이 아닙니다. 전방 예산은 32 MiB입니다. mpv 디스크 캐시는 사용하지 않지만 임시 조각 처리용 저장 공간은 별개입니다. 직접 다운로드한 파일은 디스크에 남습니다.

방송 상태와 오류를 확인한 뒤 2·5·10초 간격으로 누적 최대 세 번 자동 재연결할 수 있습니다. 한도 뒤의 최종 상태 확인은 네 번째 자동 재생을 시작하지 않습니다. 인증·접근·요청 제한 오류는 복구를 멈춥니다. 수동 일시정지·정지·영상/계정 변경·시크릿 전환은 복구를 취소합니다. 방송 종료를 확인해야 다음 영상으로 자동 이동합니다. 한도 뒤 직접 다시 시도하려면 LIVE를 사용하세요. 라이브 채팅·예약 방송 대기·녹화는 포함하지 않습니다.

4. 시청 기록, 개인정보와 도구

YouTube 기록 전송은 기본으로 꺼져 있습니다. 원하면 설정에서 ‘YouTube 계정에 시청 기록 전송’을 직접 켜세요. 로컬 기록·이어보기는 별개이며, 켜는 것만으로 이전 로컬 기록을 보내지 않습니다. 보류 기록은 계정·채널과 원인을 확인한 뒤 ‘보류 중인 기록 전송 재개’로 풀어야 합니다. 실패·결과 미확인 기록은 자동 재전송하지 않습니다. 전송 응답 확인과 YouTube 기록 반영 확인은 다릅니다.

시크릿은 저장한 선택을 바꾸지 않고 전송과 로컬 기록·이어보기 저장을 막습니다. IP를 숨기거나 직접 다운로드한 파일을 지우지는 않습니다. 쿠키·인증 토큰·data/·개인 백업을 제보에 첨부하지 마세요.

수동 실험적 yt-dlp·Deno 업데이트는 다음 앱 시작에 적용합니다. Python·mpv·FFmpeg는 업데이트하지 않습니다. 완료한 과거 버전은 자동 정리나 전체 용량 상한 없이 보존합니다. 새 도구 버전을 재배포하려면 그 버전의 고지·대응소스가 필요합니다.

5. 소스, 라이선스와 검증 범위

공통 앱 소스는 FK_YT-1.1.2-source.zip이며 설치기 구현과 입력 고정 정보는 FK_YT-1.1.2-installer-source.zip에 있습니다. 다운로드 위치와 최종 SHA-256 목록은 같은 v1.1.2 릴리스 페이지에서 확인하세요. 변경 없는 외부 소스 ZIP 3개는 SOURCE-ACCESS-1.1.2.txt에서 이번 릴리스의 파일로 연결합니다. FK_YT 자체 코드·문서는 MIT이며 외부 구성요소의 원래 라이선스와 고지를 보존합니다.

최종 파일에서 실제로 수행한 검사는 릴리스 본문에 기록합니다. 빌드·메타데이터·fixture·아카이브 무결성 검사는 실제 재생이나 들리는 언어를 입증하지 않습니다. 이전의 간헐적 즉시 종료 원인은 확정되지 않았습니다. 이번 1.1.2의 대화형 UAC 설치·업데이트·제거를 새로 검증했다는 뜻도 아닙니다. 이전 안내와 검증 결과는 해당 버전의 기록입니다. 상세 제한은 FEATURES-1.1.2.md, RELEASE-1.1.2.md와 LICENSING-1.1.2.md를 참고하세요.

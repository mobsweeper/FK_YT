Other source and notices
========================
Deno's applicable MPL package sources are included in the runnable payload at
notices/deno/third-party/sources/mpl/. MPL-SOURCE-AVAILABILITY.txt and the component
indexes identify them. Preserve these sources and original notices when
redistributing the payload. The bundled Deno version remains 2.9.7.

The unchanged baseline also includes .NET/Windows Desktop 10.0.13, CPython
3.13.16, Python yt-dlp 2026.8.19 and yt-dlp-ejs 0.8.0. Retain their original
notices. Later experimental tool downloads require their own version's notices
and source; these original source ZIPs describe the original bundled tools.

The matching installer-source ZIP identifies NSIS 3.13, zlib compression,
original NSIS/MUI2/plugin notices and exact toolchain and input pins. Its
docs/BUILDING.md describes the build. Installer compilation and actual Windows
installation, UAC, update and removal checks are separate verification layers.

Historical records and verification limits
=========================================
Original 1.0, preview and earlier release documents retained in the payload
identify earlier application names, draft/publication states and source hashes.
They remain historical records. Use the 1.1.2 release source archives for the
application and installer, and this document for unchanged external mapping;
do not treat an older app-source URL as this release's corresponding source.
No historical notice is rewritten to imply that an older binary was rebuilt.

The external publication repack repaired distributor metadata/origin fields and
added recovered legal notices. Original source archives, patches and legal texts
were preserved. Four macOS-only crate blobs with unresolved standalone notice
evidence were excluded before this unchanged Windows source collection:
block 0.1.6, malloc_buf 0.0.6, objc-foundation 0.1.1 and objc_id 0.1.1.
Their cross-platform lock entries remain. This is not a complete offline
all-target Cargo source set. No additional external-source exclusions occur here.

The supplier's exact historical final librsvg Cargo.lock was not captured.
The upstream lock and a labelled reconstruction are supplied, with original
recipes and source records. Unrecoverable historical origin URLs are marked
unknown rather than invented. A full external-cohort bit-identical rebuild and
independent supplier-package GPG verification are not established. These are
verification limits, not claims that such checks passed. See the archives'
PUBLICATION-CHANGES.txt, build controls and source indexes for details.

When providing binaries through network distribution, supply matching source
with equivalent copying access and no extra source-access fee, with clear
directions beside binary downloads. Keep source access available while offering
the binaries under this arrangement. Source access must consist of matching
files, not an unfulfilled promise to provide source later. Modified distributions
must preserve notices and supply source for their own changed binaries. A link
to an upstream latest branch does not identify that source. Check the release
page for access to the exact listed archives and their final hashes.

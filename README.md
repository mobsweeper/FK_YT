# FK_YT

YouTube 웹페이지를 상주시켜 두지 않는 Windows x64 개인 뷰어입니다. C# WPF 화면에서 필요한 목록을 읽고, mpv + yt-dlp로 영상을 재생합니다. 영어·한국어·일본어를 지원하는 다크 화면이며, 연결한 Google 계정에 속한 YouTube 채널을 선택해 사용할 수 있습니다.

## 실행

이번 릴리스는 **FK_YT-qualityreview-r4-20261016**입니다. 새 ZIP을 별도 폴더에 모두 압축 해제하고, 그 안의 **`FK_YT/Start-FK_YT.cmd`** 또는 `FK_YT.exe`를 실행하세요. `runtime`, `worker`, DLL과 notices 폴더를 실행 파일과 함께 유지해야 합니다. 배포용 ZIP은 개인 데이터를 제외하며, 개인백업 ZIP은 현재·이전 데이터를 따로 포함합니다. 개인백업을 다른 사람에게 공유하지 마세요. 초보자용 설치·Firefox 전용 프로필·업데이트 절차는 ZIP 최상위의 `사용설명서.txt`에 있습니다.

기존 설치 폴더·실행기·바로가기·ZIP은 자동으로 바뀌지 않습니다. 기존 기록을 이동하려면 앱을 종료한 뒤 기존 `data` 한 세트를 새 실행 폴더로 복사하고, 새 버전을 확인하기 전까지 원본을 보관하세요. 설정과 기록은 쓰기 가능한 `data` 폴더에 저장합니다. 개발용 `dist/FK_YT-qualityreview-r4-20261016` publish 폴더만으로는 외부 도구가 모두 포함되지 않으므로, 사용자 실행은 runtime까지 묶은 ZIP을 기준으로 합니다.

이번 후속 수정과 보류 근거는 `FK_YT_고화질후속_r4_수정판정_20261016.md`에 기록합니다. 화질 재로드 직전·대기 중 최신 재생/정지 입력 보존과 설치·게시 파일 경계를 보완합니다. r3의 원본 자막·팝아웃·다운로드 언어 수정은 `FK_YT_고화질후속통합_수정판정_20261016.md`에 보존합니다. 같은 영상의 화질 변경 시 일시정지 보존, 준비 자막의 원본 언어 대응, 독립 팝아웃 메뉴 소유자, 다운로드 안내 언어 갱신을 보완했습니다. 개발 도구의 대표 실행 파일 검증과 누락 고지 파일의 기존 해시 보존도 강화했습니다. 전체 런타임 보조 파일의 출처 인증은 별도 미완료 범위입니다. 일부 영상의 자동 전환 시 약 5초 버퍼링은 원인이 아직 확인되지 않았으며 확인 목록으로 유지합니다.

이번 15개 모델 후속 검토의 수정·보류·테스트 범위는 `FK_YT_고화질통합리뷰_수정판정_20261016.md`에 기록했습니다. 선택 계정의 메타데이터 실패 안내, 직접 스트림 헤더 입력 상한, 다운로드 진행률 대기열, 배포 의존성 잠금을 보완했습니다. 이전 후속 화질 메뉴 수정·리뷰 판정·검증 범위는 `FK_YT_고화질후속리뷰_수정판정_20261015.md`에 기록했습니다. 이전 360p 제한 수정과 실제 재생 검증은 `FK_YT_고화질복구_검증결과_20261015.md`에 기록했습니다. 이전 통합 리뷰는 `FK_YT_통합수정_검증결과_20261015.md`, UI 언어 검증은 `FK_YT_UI언어_구현검증_20261015.md`에 보존합니다. 이전 문서의 결과는 해당 버전의 기록입니다.

기본 화질은 **최고 화질 (자동)**입니다. 화질 목록에서 이 항목을 선택하면 다음 영상마다 제공되는 최고 화질을 사용합니다. **최대 1080p** 같은 숫자는 해당 해상도 이하로 제한하는 설정이며, 현재 영상에서 가장 높은 숫자여도 자동 모드와 구분합니다. 1080p 상한에서 다음 영상이 720p까지만 제공되면 720p 이하 최고 화질로 재생하고 상한은 유지합니다. 아직 설정 전환을 거치지 않은 구형 화질 제한만 한 번 최고 화질로 전환하며, 이후 직접 선택한 제한은 저장합니다. 고해상도는 네트워크·GPU 사용량을 늘릴 수 있습니다. 화질 목록은 버튼을 눌렀을 때 조회하므로 기본 재생을 위해 중복 추출하지 않습니다.

일부 로그인 계정에서 360p 주소만 받던 경우, 선택한 계정을 그대로 사용해 추가 HLS 경로도 조회합니다. 영상·음성이 합쳐진 고화질도 자동 선택과 직접 재생·다음 영상 준비에 사용합니다. 서버가 현재 계정에 제공하는 주소가 기준이며 모든 영상의 4K를 보장하지 않습니다. 이미 직접 저장한 360p 등의 화질 상한은 유지하므로 최고 화질을 원하면 화질 메뉴의 **최고 화질 (자동)**을 선택하세요.

설정 파일을 읽을 수 없으면 기존 파일과 로그인 정보는 보존하고 재생·로그인 조회·기록 저장을 잠시 막습니다. 파일 접근·형식 문제를 해결한 뒤 앱을 다시 실행하세요. 정상적인 첫 실행에는 이 제한을 적용하지 않습니다.

처음에는 검색어 또는 YouTube 영상·채널·재생목록 URL로 시작할 수 있습니다. 개인 추천·구독·비공개 목록은 **설정 · 로그인**에서 연결합니다.

1. Firefox 프로필을 선택합니다. 필요하면 **브라우저에서 로그인**을 눌러 실제 Firefox에서 YouTube에 로그인합니다.
2. **Firefox 세션 연결 / 갱신**을 누릅니다. 이후 브라우저를 계속 열어둘 필요는 없습니다.
3. 또는 Netscape 형식 `cookies.txt`를 가져옵니다. 원본은 수정하지 않습니다.
4. 다른 YouTube 계정으로 교체할 때에는 **다른 계정으로 연결**을 체크하여 로컬 기록을 분리합니다. 같은 계정의 세션 갱신은 체크하지 않습니다.

연결 후 왼쪽 **YouTube 채널**에서 같은 Google 계정의 채널을 선택합니다. 선택한 채널의 홈·구독·재생목록·Shorts를 조회하고, 로컬 시청 기록과 이어보기는 채널별로 분리합니다. 원하는 채널이 없으면 **채널 목록 갱신**을 누르세요. 시크릿 모드에서는 채널 선택을 사용할 수 없습니다.

쿠키는 YouTube/Google 도메인만 추리고 Windows 사용자 계정의 DPAPI로 암호화합니다. 도구에 전달하는 복사본은 현재 사용자와 SYSTEM만 접근 가능한 `data/temp`에 잠시 만듭니다. 일반 VOD 추출 완료가 확인되면 재생용 복사본을 먼저 삭제합니다. 라이브·확인 불가 경로는 재추출을 위해 재생 정지까지 유지할 수 있습니다. 다른 PC/Windows 계정으로 배포본을 옮기면 다시 연결해야 합니다. 개인 `data`를 다른 사람에게 배포하지 마세요.

앱의 쿠키·다운로드 임시 작업 경로는 junction이나 심볼릭 링크를 통한 연결을 허용하지 않습니다. 앱 폴더나 TEMP의 상위 경로가 이러한 연결이면 일반 폴더 경로를 사용하세요. 사용자가 선택한 최종 다운로드 목적지의 상위 연결은 사용할 수 있습니다. 썸네일 디스크 경로가 차단되면 이미지는 메모리에서만 처리합니다.

## 표시 언어

왼쪽 설정 버튼 아래에서 English / 한국어 / 日本語를 선택합니다. 선택은 앱 폴더의 `data/settings.json`에 저장되어 다음 실행에도 적용됩니다. 앱 버튼·안내문만 바꾸며 YouTube 계정 지역, 추천 요청 언어, 자막 선호 설정은 변경하지 않습니다. 영상 제목·댓글·서버 분류 탭은 원문을 유지합니다. 재생을 재시작하지 않으며, 설정 저장 실패 시 이전 언어를 유지합니다. 같은 앱 폴더의 채널들에는 동일한 UI 언어를 사용합니다.

## 탐색과 재생

- **재생 화면 모드:** 전체화면 아이콘 옆의 넓은 사각형 아이콘은 영화관 모드입니다. 왼쪽 메뉴·검색창·오른쪽 패널·채널/평가 정보를 접어 창 안에서 영상을 넓게 보여줍니다. 다시 누르면 원래 배치로 돌아옵니다. 아이콘에 마우스를 올리면 설명이 나옵니다.
- **오른쪽 패널:** 댓글 보기 옆의 접기 아이콘을 누릅니다. 영상 제목 오른쪽의 펼치기 아이콘으로 같은 탭과 목록을 다시 표시합니다. 전체화면 전후에도 접기 상태를 보존합니다.
- **전체화면·팝아웃:** 약 3초 동안 조작하지 않으면 하단 메뉴가 내려가며 숨습니다. 영상 영역 아래쪽에 마우스를 움직이거나 키보드를 조작하면 다시 나타납니다. 재생바·음량을 드래그하거나 자막/화질 메뉴를 열어 둔 동안에는 숨지 않습니다. 일반 화면·영화관에서는 메뉴가 계속 보입니다.

- 메인 카드·다음 재생·관련 추천의 **채널 프로필 이미지/이름**, 재생 영상 아래의 **채널 프로필 이미지/이름**을 누르면 해당 채널 영상 페이지를 엽니다. 명시된 채널 주소나 ID만 사용하며, 프로필 이미지가 없으면 기본 표시를 씁니다.
- 채널 페이지에는 채널 정보와 YouTube가 제공하는 정렬 탭이 나옵니다. **최신순·인기순·오래된순** 모두 서버가 반환한 순서와 다음 페이지를 그대로 사용합니다. 첫 90개를 앱에서 뒤집거나 조회 수로 재정렬하지 않습니다. 서버가 제공하지 않는 탭은 만들지 않습니다. **멤버십 전용 영상 숨기기**는 채널 페이지에도 적용하며 제외한 항목 다음부터 이어서 채웁니다.
- 홈 추천 위에는 선택한 YouTube 채널의 실제 분류 탭이 표시됩니다. 예: **All / Music / Mixes / New to you**. 이름·순서·종류는 계정과 서버 응답에 따라 달라집니다. 탭을 누르면 그 분류를 새로 조회하며 이전 분류의 항목과 섞지 않습니다. 조회가 끝난 뒤 새로고침하면 현재 분류를 다시 엽니다.
- 처음 최대 90개를 순서대로 표시하고 목록 끝에 가까워지면 다음 최대 90개를 추가합니다. 서버가 목록 끝을 반환하면 종료합니다. 새로고침은 처음부터 새 조회를 시작합니다.
- 다음 페이지 확인 중 오류가 나도 이미 받은 목록은 화면에 유지하고 새로고침 안내를 표시합니다. 검색창은 HTTP·HTTPS·주소 앞부분을 생략한 YouTube 링크를 지원합니다. `list`가 포함된 주소는 재생목록으로 열며, YouTube 믹스는 시작 영상 정보를 보존합니다. 목록 위의 **목록 재생**으로 첫 영상부터 시작할 수 있습니다.
- 홈·Shorts·구독·검색은 중복 항목을 제외합니다. 재생목록은 순서와 중복을 유지합니다. 목록 카드에 없는 정보는 생략하며 카드별 영상 상세 추출은 하지 않습니다.
- 가상화된 카드 행과 메모리 이미지 캐시 상한 96 MiB, 디스크 썸네일 캐시 상한 약 512 MiB를 사용합니다. 다운로드는 최대 4개, 대기 요청은 최대 128개로 제한하며 화면에서 사라진 카드의 요청은 취소합니다. 디스크 목록은 한 번 조사한 뒤 크기·개수를 추적하여 정리합니다. 사용하지 않던 목록 DB 캐시는 새로 기록하지 않습니다.
- 영상 클릭 시 같은 창에서 플레이어와 **다음 재생 / 관련 추천 / 댓글 보기**를 엽니다. 다음 재생에는 최대 20개를 표시하며 맨 위 항목이 자동재생 대상입니다. 관련 추천은 선택한 채널의 YouTube 응답에서 최대 30개를 가져옵니다. 뒤로 가면 기존 목록과 스크롤 위치가 유지됩니다.
- 기본값은 실제로 사용할 수 있는 최고 화질입니다. **화질 선택**을 누르면 해당 영상이 제공하는 해상도를 조회하고 목록을 펼칩니다. 일반 재생 시작 때 화질 조회를 추가 실행하지 않으며, 미리 준비한 영상의 화질 정보는 재사용합니다. 조회 실패 시 버튼으로 재시도할 수 있습니다. 화질 변경 시 현재 위치에서 다시 로드하며 같은 영상의 화질 목록·채널 정보·관련 추천·열린 댓글을 유지합니다. **자막 ▾**를 누르면 플레이어의 현재 자막과 영상이 제공하는 전체 언어 목록·자막 끄기가 드롭다운으로 표시됩니다. 현재 항목에는 ✓가 붙고, 다음 영상에서도 선택 언어를 우선합니다. 본창과 팝아웃에서 사용할 수 있습니다. 메뉴를 열 때 일반·자동·자동번역 자막의 전체 언어 정보를 조회하고 선택한 자막만 추가로 불러옵니다. 서버가 제공하지 않는 언어를 새로 만들지는 않습니다. 목록은 현재 영상·계정에 대해 메모리에서 5분간 재사용합니다. `Space` 재생/일시정지, `←/→` 5초 이동, `F` 전체화면, `Esc` 전체화면 해제입니다.
- 본창과 팝아웃의 **이전 / 다음**으로 영상을 바꿀 수 있습니다. 이전 버튼은 목록·추천을 오간 실제 재생 순서를 되짚습니다. 앞서 본 영상이 없으면 현재 목록의 이전 항목을 사용하며 멤버십 숨기기 설정을 적용합니다. 다음 버튼은 자동재생을 꺼도 작동합니다.
- **팝아웃**으로 재생 영상을 별도 창에 옮길 수 있습니다. 크기 조절, 항상 위, 음량·시간 이동을 지원하며 **원래 창으로** 또는 팝아웃 닫기로 복귀합니다. 같은 플레이어를 유지합니다. 본창·팝아웃의 음량 막대는 클릭한 위치로 바로 이동하고, 누른 채 드래그하면 계속 조절됩니다.
- 본창과 팝아웃에서 **영상 영역을 클릭**하면 일시정지/재개합니다. **공유** 버튼은 `https://www.youtube.com/watch?v=영상ID` 형식의 주소만 클립보드에 복사합니다. 공유 추적 ID, 재생목록, 재생 시간은 포함하지 않습니다.
- 목록의 영상 카드를 오른쪽 클릭해 **영상 링크 복사**를 선택하면 재생 중인 영상과 관계없이 그 카드의 깨끗한 영상 URL을 복사합니다. 재생이나 목록 이동을 시작하지 않으며 재생목록·채널 카드의 영상 공유는 비활성화됩니다. 기존 관심 없음·이 채널 추천 안 함 메뉴도 유지합니다.
- 플레이어 위쪽 영상 제목을 누르면 **영상 설명 버블**을 여닫습니다. 기존 관련 영상 응답의 설명을 사용해 별도 추출을 더하지 않으며, 읽기 전용 본문에서 문장을 선택·복사하고 긴 설명을 스크롤할 수 있습니다. 제목 재클릭이나 닫기 버튼으로 닫으며 영상·계정 전환·목록으로 이동할 때도 닫힙니다.
- 인증이 필요한 영상은 영상 아래 **인증이 완료된 쿠키가 필요합니다** 알림을 표시합니다. **다음 영상 자동재생**이 켜져 있으면 7초 후 다음 영상을 시도하며 **다음 재생 취소**, 자동재생 끄기, 목록으로 돌아가기, 영상·계정 전환은 대기를 취소합니다. 다음 영상이 없거나 목록을 확인하지 못하면 정지합니다. 일반적인 경고 확인은 자동 동의하지만 로그인·연령 인증 자체를 우회하지는 못합니다. 인증이 필요하면 일반 모드의 전용 Firefox 프로필에서 인증 후 연결을 갱신하세요.
- 영상 아래 **좋아요 / 싫어요**는 선택한 YouTube 채널에 반영됩니다. 현재 선택한 버튼을 다시 누르면 취소합니다. **내 평가 확인**으로 서버 상태를 다시 읽으며, 확인되지 않은 결과를 성공으로 표시하지 않습니다. 로그인 채널이 없거나 시크릿 모드이면 평가 버튼은 비활성화됩니다.
- 좋아요·싫어요 수치는 [Return YouTube Dislike](https://returnyoutubedislike.com/)에서 조회합니다. 싫어요는 **추정치(≈)**이며 YouTube 공식 합계가 아닙니다. 수치는 지연될 수 있고 내 평가와 별도로 표시합니다. RYD에는 영상 ID만 전송하며 로그인 쿠키·계정 정보를 보내거나 RYD에 별도로 투표하지 않습니다. 일반 모드는 재생 영상당 조회하고 5분 동안 메모리에만 캐시합니다. 시크릿 모드는 **수치 보기**를 눌렀을 때만 조회합니다. 오류나 요청 제한은 재생·댓글을 막지 않습니다.
- 댓글은 **댓글 보기**를 눌렀을 때 인기순/최신순으로 최대 100개를 조회합니다. 재생 시작과 자동재생만으로 댓글을 추출하지 않습니다. 댓글 오류는 재생을 중단하지 않습니다. 댓글 작성, 구독/재생목록 편집, 라이브 채팅은 포함하지 않습니다.

## 다음 영상 준비와 다운로드

자동재생이 켜져 있고 현재 영상이 마지막 60초에 들어가면 다음 영상 하나의 스트림을 미리 준비합니다. 현재 영상 데이터 읽기가 끝나는 지점에서 mpv가 다음 영상의 영상·음성 일부를 받으며, 전환할 때 준비된 재생을 이어 사용합니다. 현재 목록을 우선하고 목록이 정상적으로 끝나거나 주소로 직접 재생한 경우 관련 추천으로 이어집니다. 아직 다음 페이지가 남거나 페이지 조회에 실패한 목록은 추천으로 건너뛰지 않습니다.

계정·시크릿·화질·영상·다음 대상 변경 또는 자동재생 OFF 시 오래된 준비를 사용하지 않습니다. 준비 실패·라이브·지원하지 않는 스트림은 일반 재생 경로로 돌아갑니다. 네트워크와 스트림 상태에 따라 전환 대기는 남을 수 있습니다. 버퍼 설정은 앞쪽 15초/32 MiB, 뒤쪽 8 MiB이며 압축 데이터에 대한 설정입니다. 준비용 내부 캐시는 취소 후 다음 로드/정지까지 남을 수 있으므로 이를 앱 전체 RAM/VRAM 또는 취소 즉시 메모리 해제 상한으로 해석하지 않습니다.

**다운로드**를 누르면 선택한 화질 이하의 영상과 음성을 MKV 파일 하나로 저장합니다. 저장 위치를 고른 뒤 창 하단에서 진행률을 확인하거나 **다운로드 취소**를 누를 수 있습니다. 목록·설정으로 이동해도 다운로드 상태와 취소 버튼을 사용할 수 있습니다. 한 번에 한 건을 실행하며 계정 변경·앱 종료 시 진행 작업을 정리합니다. FFmpeg가 영상·음성을 합칩니다. 조각 파일은 앱 전용 임시 폴더에서 처리하며, 완성 파일만 목적지에 복사한 뒤 최종 이름으로 교체합니다. 복사 중 취소·실패하면 기존 파일은 보존합니다. 클라우드가 최종 복사 파일을 여는 것까지 막지는 못합니다. 다운로드는 시청 기록 전송을 발생시키지 않으며, 시크릿 모드에서는 로그인 쿠키 없이 다운로드합니다.

## Shorts·목록 옵션·추천 설정

- 왼쪽 **Shorts**는 선택한 채널의 개인화 Shorts 전용 피드를 읽습니다. YouTube의 Shorts 시작점과 연속 추천 토큰을 이용하며 로그인 연결이 필요합니다. 서버가 제목·채널 정보를 함께 주지 않은 카드에는 썸네일과 **Shorts 영상**을 표시합니다. 정보를 채우려고 목록의 모든 영상을 추가 추출하지 않습니다.
- **설정 · 로그인 → 멤버십 전용 영상 숨기기**는 기본으로 켜져 있습니다. YouTube가 목록에서 멤버십 전용으로 표시한 영상만 거릅니다. 표시 정보가 없는 영상은 재생을 선택한 뒤 제한이 확인될 수 있습니다. 설정을 바꾸면 현재 목록을 다시 조회합니다.
- 재생 화면의 **다음 영상 자동재생**은 기본으로 켜져 있습니다. 영상이 정상적으로 끝나면 다음 재생 목록의 맨 위 영상을 0초에서 시작합니다. 재생목록에 같은 영상이 여러 번 있어도 각 순서를 유지합니다. 일반 오류·수동 정지에는 자동으로 넘어가지 않으며 인증필요 오류는 위의 7초 대기 안내를 사용합니다. 필요한 경우 다음 목록을 최대 네 번 더 조회합니다.
- 추천 카드에서 오른쪽 클릭해 **관심 없음** 또는 **이 채널 추천 안 함**을 선택합니다. YouTube가 해당 카드에 제공한 동작만 활성화되며, 선택하면 실제 계정의 추천 설정에 요청을 보냅니다. 서버의 성공 응답을 받은 뒤 현재 목록에서 항목을 제외합니다. 모든 카드에 메뉴가 제공되는 것은 아닙니다.

## 시크릿 모드

왼쪽 **시크릿 모드**를 켜면 진행 중인 계정 작업을 정리하고 로그인 쿠키 없이 재생합니다. 검색어·영상·공개 재생목록 주소를 사용할 수 있습니다. 개인 목록, 채널 전환, 추천 설정 전송, YouTube 시청 기록 전송을 사용하지 않으며, 앱의 시청 기록과 이어보기 위치도 저장하지 않습니다. 모드를 끄면 연결한 채널을 다시 사용할 수 있습니다. 기존에 저장한 계정과 기록은 유지됩니다.

시크릿 모드에서도 공개 영상 재생과 댓글·화질 조회는 YouTube에 접속하며, 앱의 일반 설정은 유지됩니다. 시크릿 썸네일은 디스크를 읽거나 쓰지 않고 메모리에서만 사용하며 모드 전환 시 비웁니다. 사용자가 직접 저장한 다운로드 파일은 남습니다.
인증 오류나 경고 확인이 발생해도 시크릿 모드의 쿠키 미사용은 유지합니다. 로그인·연령 인증을 요구하는 영상은 시크릿 모드에서 재생하지 못할 수 있습니다.

## 시청 기록

목록·댓글·일반 재생 정보 추출은 `no-mark-watched`를 사용합니다. 실제 재생 누적 30초 또는 30초 미만 영상의 80% 이후에만 별도 기록 전송을 시도합니다. 일시정지·버퍼링·탐색 이동은 누적에서 제외합니다. 30초 기준은 실제 시간, 짧은 영상 80% 기준은 재생한 미디어 시간입니다.

**yt-dlp 기록 전송은 YouTube에서 거의 완주한 것으로 표시될 수 있습니다.** 이 동작은 설정에서 끌 수 있습니다. 정확한 이어보기는 SQLite에 5초마다, 일시정지·영상 전환·종료 시 저장합니다. YouTube 다른 기기와 정확한 재생 위치를 동기화하지 않습니다.

로컬 기록의 상태는 `로컬 저장 → 전송 중 → 전송됨 · 반영 미확인`입니다. **YouTube 기록 확인**에서 실제 계정 기록에 나타난 영상에만 `계정 기록에서 확인됨`을 표시합니다. 자동 재시도는 최초 시도 후 최대 2회입니다. 기록 전송 실패는 재생을 막지 않습니다. 동기화를 끄면 대기 전송과 재시도를 취소합니다. 이미 YouTube로 전달된 요청은 취소로 되돌릴 수 없으므로 전송 도중 취소된 경우 반영 미확인으로 표시합니다.

## 빌드와 배포

PowerShell에서 프로젝트 폴더를 기준으로 실행합니다. 시스템 SDK/Python/PATH를 변경하지 않습니다.

```powershell
pwsh -NoProfile -File scripts/Bootstrap.ps1
pwsh -NoProfile -File scripts/Bootstrap-Ffmpeg.ps1
pwsh -NoProfile -File scripts/Build.ps1
pwsh -NoProfile -File scripts/Publish.ps1
```

버전·다운로드 출처·해시는 `dependencies.lock.json`, 준비 방법은 `TOOLCHAIN.md`를 확인하세요. .NET 10 SDK는 `tools/dotnet`, Python 3.13·yt-dlp·Deno·mpv·FFmpeg는 `runtime`에 설치합니다. 배포는 win-x64 self-contained이며 `data`, SDK, 소스 검증 산출물은 포함하지 않습니다.

구성:

| 위치 | 역할 |
|---|---|
| `src/FkYouTube` | WPF 앱, SQLite 기록, DPAPI 세션, 썸네일 캐시 |
| `src/FkYouTube/Playback` | mpv HWND 및 named-pipe JSON 제어 |
| `src/FkYouTube/ProcessSupport` | suspended spawn 후 Windows Job Object 연결 |
| `worker` | lazy 목록, 개인 Shorts·관련 추천, 채널 세션, 추천 설정 |
| `tests/FkYouTube.Tests` | 가짜 데이터로 실행하는 C# 검증 |
| `artifacts` | 테스트·UI·재생 검증 결과 |

## 검증

검증 결과와 기능별 완료/미검증 상태는 `VERIFICATION.md`에 기록합니다. 계정 반영, 원격 추천 품질, 브라우저 대비 성능, 모니터 간 실제 DPI/마우스 입력은 별도의 실환경 검증이 필요합니다. fixture나 화면 렌더 결과를 실계정 또는 실제 입력의 성공으로 취급하지 않습니다.

```powershell
runtime/python/python.exe -m unittest discover -s worker -p "test_*.py" -v
tools/dotnet/dotnet.exe run --project tests/FkYouTube.Tests
# 빌드 후 네트워크 없는 UI 검사
src/FkYouTube/bin/Release/net10.0-windows/FK_YT.exe --demo --ui-smoke-output artifacts/ui
# 로그인 없는 공개 영상 재생 검사 (실제 네트워크 사용)
src/FkYouTube/bin/Release/net10.0-windows/FK_YT.exe --playback-smoke-output artifacts/playback
```

위 UI·공개 재생 진단 모드는 계정 기록을 전송하지 않습니다. 별도의 `--account-playback-smoke-output <폴더>`는 연결된 계정으로 실제 재생하여 시청 기록을 전송할 수 있으므로 계정 검증을 의도할 때만 사용합니다. `--root <폴더>`로 데이터/도구 기준 경로를 지정할 수 있습니다. 동시에 같은 폴더의 앱은 하나만 실행합니다. 정상 종료와 강제 종료에서 앱이 생성한 Python/mpv/yt-dlp/Deno/FFmpeg 자식은 Job Object로 함께 종료합니다. 비정상 종료로 남은 임시 쿠키는 다음 실행 때 정리합니다.

전용 Firefox 프로필 연결 이후 기능별 소스 변경 내역은 프로젝트 루트의 `CHANGES_AFTER_PROFILE.txt`에 정리했습니다.

YouTube의 내부 응답·세션 정책이 바뀌면 일부 목록이나 재생이 실패할 수 있습니다. 앱은 지원되지 않은 기능을 성공한 것처럼 표시하지 않으며, 로그인 만료와 연결 실패를 구분해 안내합니다.

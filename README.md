# FK_YT 1.0

Windows용 개인 YouTube 뷰어. 필요한 목록과 플레이어를 한 창에 모았습니다.

A personal YouTube viewer for Windows, with browsing and playback in one window.

**[한국어 안내 · 스크린샷](readme_KR.md)** · **[English guide · Screenshots](readme_EN.md)**

간단한 사용에는 **`1.0 portable.zip`을 권장합니다.** EXE 설치기의 검증 스크립트가 파일별 SHA-256을 확인하는 데 시간이 걸릴 수 있으며, 앱·재생 기능은 두 방식 모두 같습니다.

**`1.0 portable.zip` is recommended for straightforward setup.** The EXE installer's verification script checks SHA-256 hashes file by file, which can take time; both versions offer the same app and playback features.

2026-10-16 확인: 설치기와 포터블은 로컬 검증을 마쳤지만, 저장소는 비공개이고 `v1.0`은 드래프트입니다. 아직 공개 다운로드는 없습니다.

Checked October 16, 2026: installer and portable builds have been locally verified, but the repository is private and `v1.0` is a draft. Public downloads are not available yet.
